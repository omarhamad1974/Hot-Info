# Changing the logo and the header text from the admin page

1. Upload this folder to GitHub (replace the files) and wait 1-2 minutes.
2. Open admin.html > Website content > tab **General**.
3. **Logo**: press the upload arrow and choose your picture (a PNG with a transparent background looks best).
   It is used in the header of every page, on the home page and on the About page.
4. **Header text next to the logo**: type the text. Leave it empty to use the built-in "Intellectual Properties".
5. Press **Save to GitHub**. The site updates in 1-2 minutes.
6. Arabic text: open General and fill the Arabic boxes (right side), the same
   "Header text" box in Arabic. Save.

If the new logo does not appear, the picture file could not load: the site then shows the old logo,
and if that also fails, the letters KHIP. Hard-refresh (Ctrl+Shift+R) after saving.

# Phase 12a: how to use the Brand tab

1. Upload this folder to GitHub (replace the files). Wait 1-2 minutes.
2. admin.html > Website content > **General** > **Brand** (sub-tab).
3. **Logo and name**: upload the logo, type the name that appears after the vertical line.
4. **Brand palette**: change any of the 7 colors (name, color picker or hex code). Press
   "Use this palette for the whole site" to copy them into General > Colors, then Save to GitHub.
5. **Fonts and text colors**: for H1, H2, H3 and body choose a font and a color. "Site default" keeps the current look.
6. **Your own fonts**: Upload font, then pick it in the lists above. Tick "has Arabic" only if the font really includes Arabic letters.
7. Press **Save to GitHub**. The site updates in 1-2 minutes. Hard-refresh (Ctrl+Shift+R) to see it.

Section backgrounds (Sections tab > each section > Style) now list your brand colors first.
